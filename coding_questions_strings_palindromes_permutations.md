# 🔹 Palindrome-Based Questions (Strings)

## 🟢 Beginner Level
1) Check if a String is a Palindrome
   - Write a function to check whether a given string is a palindrome.

2) Case-Insensitive Palindrome
   - Check if a string is a palindrome ignoring case sensitivity.

3) Alphanumeric Palindrome
   - Check if a string is a palindrome considering only alphanumeric characters (ignore spaces and symbols).

4) Reverse String Without Using Built-in Functions
   - Reverse a string manually and verify if it is a palindrome.

5) Palindrome Number (String Approach)
   - Convert an integer to string and check if it is a palindrome.

## 🟡 Intermediate Level
6) Longest Palindromic Substring
   - Given a string, return the longest palindromic substring.

7) Count Palindromic Substrings
   - Count how many substrings in a string are palindromes.

8) Valid Palindrome After Deleting One Character
   - Check if a string can become a palindrome after deleting at most one character.

9) Check if Any Permutation is a Palindrome
   - Determine whether any permutation of a string can form a palindrome.

10) First Non-Repeating Character in a Palindrome String
   - Given a palindrome string, find the first character that appears only once.

## 🔴 Advanced Level
11) Minimum Insertions to Make a String Palindrome
    - Find the minimum number of insertions required to convert a string into a palindrome.

12) Minimum Deletions to Make a String Palindrome

13) Partition String into Palindromes
    - Return all possible palindrome partitioning combinations of a string.

14) Check Palindrome Using Recursion Only

15) Find All Palindromic Subsequences

16) Longest Palindromic Subsequence (DP Problem)

17) Palindrome Pairs
    - Given a list of words, find all pairs that form a palindrome when concatenated.
